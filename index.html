01 / BUSINESS SYSTEM

Inventory Control

Платформа складского учёта для деревообрабатывающего предприятия.

МОЯ РОЛЬ

Главный backend-разработчик; по совместительству — системный и бизнес-аналитик

Задача и мой вклад

Система покрывает приёмку и отгрузку товара, управление остатками и партиями, формирование отчётности. Я собираю и анализирую требования, проектирую бизнес-процессы и реализую backend в рамках чистой слоистой архитектуры.

  • Проектирование REST API, контрактов и бизнес-валидаций.
  • Аутентификация и авторизация: OAuth 2.0, RSA JWT и API Gateway.
  • Каскадная валидация данных на уровнях Pydantic, доменной логики и PostgreSQL.
  • Обмен событиями через Outbox и Kafka, отдельный worker для отчётности.
  • Управление зависимостями через Dishka, миграции Alembic, CI/CD и мониторинг.

Технологии

PythonFastAPIPostgreSQLSQLAlchemy 2.0DishkaRedisKafkaDockerGitHub Actions

МОЯ РОЛЬ

Backend-разработчик

Задача и мой вклад

Разрабатывал backend платформы для проведения проверочных работ. Проектировал хранение данных, реализовывал контроль времени прохождения и настраивал инфраструктуру.

  • Спроектировал модели БД в SQLAlchemy ORM и настроил миграции через Alembic для версионирования схемы данных. Оптимизировал запросы для выборки результатов по группам и периодам.
  • Реализовал механизм тайминга проверочных работ: серверную фиксацию времени начала, контроль дедлайна и автоматическое завершение сессии при истечении лимита.
  • Внедрил кэширование банка вопросов и конфигураций проверок в Redis, снизив нагрузку на PostgreSQL при одновременном прохождении проверок несколькими группами.
  • Настроил полностью автономный деплой через Docker Compose.
